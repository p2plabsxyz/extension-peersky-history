💡 How to search

You can search through your history using fuzzy matching.

  • Don't worry about capitals - search is case-insensitive
  • Match letters or starts of words with spaces in between
  • The search is done on latest entries first
  • Results match against both URL and page title

Examples:
• "peersky docs" → matches "Peersky Documentation"
• "github repo" → matches GitHub repository URLs
